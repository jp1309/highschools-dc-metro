    Cómo leer este mapa

    Fuentes y metodología

    Las ubicaciones corresponden a las coordenadas publicadas para cada escuela. Las zonas se dibujan únicamente cuando existe una correspondencia explícita entre el nombre del límite y un identificador escolar; el sitio no hace emparejamientos aproximados.

    Las jurisdicciones publican sus límites en ciclos distintos. El año escolar, tipo de límite y fuente se muestran en cada ventana del mapa. Una zona municipal o aproximada no se presenta como zona oficial de asistencia.

    Limitaciones importantes
    • Las calificaciones heredadas se identifican como no verificadas y no entran en el promedio. Solo una entrega autorizada, completa y trazable puede marcarlas como verificadas.
    • Los límites pueden cambiar entre ciclos escolares; confirme la asignación con el distrito antes de tomar una decisión.
    • Las escuelas sin una zona vinculada continúan visibles como puntos y se contabilizan una sola vez.
